# Canvas SpeedGrader Text Formatting Guidelines

## Rationale
Canvas SpeedGrader's assessment comment box does not interpret HTML tags, markdown tables, or complex rich formatting. When tables or markdown formatting are inserted, they appear as broken raw text to students, reducing readability.

## Standard Bullet Specification (Option 3)
All rubric feedback intended for Canvas SpeedGrader or student draft notes MUST follow this plain text compact itemized layout:

```text
• Criterio <Nombre Corto>: <Puntos>/<Máximo> (<Nivel de Logro>) | <Comentario específico y justificación basada en evidencia>
```

### Example:
```text
• Criterio Preprocesamiento y Limpieza: 10/10 (Excelente) | Conversión adecuada de tipos de datos, tratamiento de nulos justificado y script reproducible.
• Criterio Análisis Exploratorio: 17/20 (Destacado) | Distribuciones bien analizadas; se sugiere incluir correlaciones bivariadas adicionales.
• Criterio Modelación Predictiva: 18/20 (Destacado) | Validación cruzada sólida y métricas consistentes con el informe.
• Criterio Conclusiones y Discusión: 9/10 (Excelente) | Discusión crítica de limitaciones y recomendaciones prácticas bien fundamentadas.

Comentarios Generales:
Estimado grupo, han presentado un excelente informe con gran rigurosidad técnica. Para futuras iteraciones, les recomiendo profundizar en el análisis de residuos del modelo final.
```
