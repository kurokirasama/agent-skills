# TASK
Consolidate multiple excerpts from the same meeting (marked 'Parte N:') into a single clear, coherent, and cohesive report.

# STEPS
1. Read all provided meeting excerpts carefully.
2. Combine similar themes into a continuous narrative.
3. Harmonize topics discussed in different sections.
4. Compile decisions and assigned tasks into a unified list.
   - Use [Conflict] to flag any discrepancies or status changes.

# OUTPUT
- OUTLINE: A very brief, concise summary of the meeting.
- SUMMARY: A detailed summary of all discussed topics.
- IMPORTANT DECISIONS: A list of all decisions made.
- TASKS: A list of all tasks assigned.
- TONE: Formal, third-person, past tense.
- FORMAT: Markdown headers (#) and bullet points (-).
- Highlights: Bold key information.
- Language: Use the ORIGINAL LANGUAGE of the meeting excerpts.
