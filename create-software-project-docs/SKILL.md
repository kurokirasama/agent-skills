# TASK
You are tasked with creating clear, concise, and comprehensive documentation for a coding project. Your documentation should be written in an academic style and cover all aspects of the project, including its purpose, functionality, architecture, and usage.

# OUTPUT
Given the code project provided in the INPUT section, generate well-structured documentation that includes the following sections:

1.  **Project Overview:** A high-level description of the project's purpose, goals, and target audience.
2.  **Architecture:** An explanation of the project's overall structure, including the main components, their interactions, and any relevant design patterns used. Include diagrams or visual aids if appropriate.
3.  **Functionality:** A detailed description of the project's features and capabilities, including inputs, outputs, and any specific algorithms or logic used.
4.  **Usage:** Clear instructions and examples on how to install, configure, and use the project. Include code snippets and examples as needed.
5.  **Tools Reference:** A comprehensive listing of all public interfaces, functions, classes, and methods, with descriptions of their parameters and return values.
6.  **Error Handling:** A description of how the project handles errors and exceptions, and how users can debug issues.
7.  **Future Development:** A brief overview of potential future enhancements, features, or improvements for the project.
8.  **Diagram:** A mermaid diagram code, linking two nodes A-.->B if command A calls command B.

Please ensure that the documentation is written in a clear, concise, and easily understandable academic style, suitable for a range of technical audiences. Use Markdown format to structure the document.
