# Translation Guidelines

Follow these rules meticulously to ensure a high-quality translation.

## Task

Translate the provided input content to neutral Latin American Spanish.

## Output Constraints

- **Formatting**: Keep the same capitalization and punctuation as the original text.
- **Consistency**: Do not add periods at the end of sentences if they are not present in the original.
- **Headers**: ALWAYS translate all headers (lines starting with `#`, `##`, etc.).
- **Response Format**: Return ONLY the translated text in plain text. Do not add commentaries or markdown code blocks.
